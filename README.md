# VektraTool

Free online tools for everyday digital tasks. Everything runs in your browser, with no signup and no installs.

🌐 **https://www.vektratool.com**

## Popular tools

**Image tools**
- [Compress image to 20KB](https://www.vektratool.com/image-tools/compress-image-to-20kb): shrink photos to the exact size online forms ask for
- [Passport photo maker](https://www.vektratool.com/image-tools/passport-photo-maker)
- [Signature resizer](https://www.vektratool.com/image-tools/signature-resizer)
- [All image tools](https://www.vektratool.com/image-tools): resize, crop, and convert JPG, PNG and WebP

**Calculators**
- [EMI calculator](https://www.vektratool.com/calculator-tools/emi-calculator)
- [GPA calculator](https://www.vektratool.com/calculator-tools/gpa-calculator)

**Text and developer tools**
- [JSON formatter and validator](https://www.vektratool.com/utility-tools/json-formatter)
- [Word counter](https://www.vektratool.com/text-tools/word-counter)
- [QR code generator](https://www.vektratool.com/utility-tools/qr-code-generator)
